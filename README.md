# LocalDictate

Строго офлайн диктовка для Windows. Русский и английский без облака.

## Что делает

1. Глобальный хоткей начинает и останавливает запись.
2. Речь распознаётся локально (Whisper / whisper.cpp через Whisper.net).
3. Текст вставляется в активное окно.
4. История хранится только на диске (`%LocalAppData%\LocalDictate`).

Сеть нужна только при первой загрузке модели. После этого приложение работает офлайн и не обращается в интернет.

## Стек

- .NET 8 / WPF (Windows 10/11 x64)
- Whisper.net
- NAudio (микрофон)
- Глобальный хоткей + вставка через буфер обмена

## Сборка на Windows

```powershell
dotnet restore
dotnet build -c Release src/LocalDictate/LocalDictate.csproj
dotnet run --project src/LocalDictate -c Release
```

## Публикация 0.2.6 (папка с нативными библиотеками Whisper)

```powershell
dotnet publish src/LocalDictate/LocalDictate.csproj -c Release -r win-x64 --self-contained false -o artifacts/LocalDictate
```

Распакуйте всю папку. Рядом с `LocalDictate.exe` должны оказаться `whisper.dll`, `ggml-*.dll` и CUDA-библиотеки (cudart/cublas 13) из пакетов runtime. Не запускайте exe отдельно от этой папки.

Установка, первый запуск и автообновление из GitHub Releases: [docs/INSTALL.md](docs/INSTALL.md). Установщик — `installer/LocalDictate.iss` (Inno Setup 6, per-user, вся папка).

Иконка: `src/LocalDictate/Assets/localdictate.svg`. Пересборка размеров — `src/LocalDictate/Assets/render-icon.sh` (нужен `rsvg-convert`). Сигналы начала и конца записи выключены (`playSoundCues: false`); если включить их в настройках, звук короткий и тихий.

## Проверка на нескольких мониторах

Облачная сборка не двигает реальные мониторы. На Windows:

1. Поставьте курсор на дополнительный монитор (в том числе слева от основного).
2. Правый Ctrl. Индикатор появляется один раз на мониторе курсора и остаётся там всю запись и расшифровку.
3. Уведите мышь на другой экран во время записи — окно не должно прыгать и не должно заезжать на соседний монитор.
4. Индикатор — скруглённая плашка «Rec» и таймер слева, цветная волна справа. Вокруг неё не должно быть лишнего прозрачного прямоугольника.
5. В тишине волна слегка дышит, на голос растёт. Ещё раз правый Ctrl — распознавание и вставка, как раньше.

## Первый запуск

1. Разрешите доступ к микрофону.
2. Дождитесь загрузки модели (`ggml-small.bin`) в `%LocalAppData%\LocalDictate\models`.
3. Правый Ctrl — запись; ещё раз — расшифровка и вставка.
